# Rock Paper Scissors Game

This is my second project built using HTML, CSS, and JavaScript.
It is a fully functional Rock Paper Scissors game that runs directly
in the browser with no frameworks or libraries involved.

## About the Project

After completing my Tic Tac Toe game, I challenged myself to build
another project to keep strengthening my frontend skills. This game
helped me go deeper into JavaScript logic, handling user input,
generating random computer choices, and updating the UI based on
the game result in real time.

## Features

- Player vs Computer gameplay
- Random computer move generation
- Win, lose, and draw result detection
- Score tracking across rounds
- Clean and responsive user interface

## Tech Stack

- HTML
- CSS
- JavaScript

## Project Structure

- index.html — the main structure of the game
- style.css — all the styling and layout
- main.js — the game logic and interactivity
